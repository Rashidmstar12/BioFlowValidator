## How to Obtain Real Data

### Option A — R/Bioconductor
```r
BiocManager::install("airway")
library(airway)
data(airway)
counts <- assay(airway, "counts")
meta   <- as.data.frame(colData(airway))
write.table(counts, "counts.tsv", sep="\t", quote=FALSE)
write.table(meta,   "metadata.tsv", sep="\t", quote=FALSE)
```

### Option B — Direct download
The processed count matrix is available from ExperimentHub:
```
https://bioconductor.org/packages/release/data/experiment/html/airway.html
```

## File Format
- `counts.tsv`: genes × samples, Ensembl IDs as row names, sample IDs as column headers, raw integer counts
- `metadata.tsv`: sample_id (index), columns: `cell` (cell line), `dex` (treated/untreated), `albut` (albuterol treatment)

## Condition Column
Use `dex` as the condition column (`untreated` / `treated`).

## Proxy Data Note
`counts.tsv` and `metadata.tsv` in this directory are synthetic proxies generated by
`datasets/generate_proxy_data.py`.  They use the same Ensembl gene ID format and
sample/condition structure as the real dataset but contain synthetic counts.
Replace with real GEO data before publication-quality benchmarking.
