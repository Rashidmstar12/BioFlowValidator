## How to Obtain Real Data

### Option A — R/Bioconductor (recommended)

```r
BiocManager::install("airway")
library(airway)
data(airway)

# Extract raw counts and minimal metadata
counts <- assay(airway, "counts")          # 63677 × 8 integer matrix
meta   <- as.data.frame(colData(airway)[, c("cell", "dex")])

# Write in BioFlowValidator format
counts_df <- as.data.frame(counts)
counts_df <- cbind(gene_id = rownames(counts_df), counts_df)
write.table(counts_df, "counts.tsv", sep="\t", quote=FALSE, row.names=FALSE)

meta_df <- data.frame(
  sample_id = rownames(meta),
  condition = meta$dex,          # untrt / trt
  batch     = meta$cell,         # cell line = biological batch
  stringsAsFactors = FALSE
)
write.table(meta_df, "metadata.tsv", sep="\t", quote=FALSE, row.names=FALSE)
```

## File Format
- `counts.tsv`: genes × samples, Ensembl IDs as row names, sample IDs as column headers, raw integer counts
- `metadata.tsv`: columns: `sample_id`, `condition` (`untrt`/`trt`), `batch` (cell line)
