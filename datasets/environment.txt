# BioFlowValidator — External Benchmark Environment Specification
#
# This file documents the Python version and package versions used to
# produce the reference benchmark results in datasets/benchmark_results.json.
#
# To reproduce the benchmark outside CI:
#
#   1. Create a virtual environment:
#      python3 -m venv venv
#      source venv/bin/activate   # or venv\Scripts\activate on Windows
#
#   2. Install dependencies:
#      pip install -r datasets/environment.txt
#
#   3. Run the benchmark:
#      PYTHONPATH=backend python datasets/benchmark_eval.py --strict
#
#   4. Run severity analysis:
#      PYTHONPATH=backend python datasets/fault_severity_analysis.py
#
# ─────────────────────────────────────────────────────────────────────────────
# Python version: 3.12 (≥3.10 required)
# ─────────────────────────────────────────────────────────────────────────────
#
# IMPORTANT: scipy>=1.11 is REQUIRED.
# Without scipy, BIO-007 (BatchConfoundingRule) silently SKIPs and
# batch_confounding recall drops to 0.000.
#
